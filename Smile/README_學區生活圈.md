# 學區生活圈（動態網頁程式設計 期末專題）

ASP.NET MVC 5（.NET Framework 4.8）＋ Entity Framework 6 Code First ＋ Bootstrap 5。

## 執行方式
1. 用 Visual Studio 開啟 `Smile.slnx`，按 F5（IIS Express）。
2. 第一次執行會自動在 LocalDB 建立資料庫 `SmileDb`，匯入 1,428 間真實店家與示範資料（約需 10 秒）。
3. 想重設資料：在 SQL Server 物件總管刪除 `SmileDb` 資料庫，再執行一次。
4. **修改過 Model（例如加了集點卡）之後，舊的 `SmileDb` 一定要先刪掉**，不然會出現「模型已變更」的錯誤。

## 頁面一覽
- 探索：首頁、附近店家、地圖模式、店家詳情、優惠列表、優惠詳情、使用教學、關於平台
- 會員：註冊（註冊完自動跑新手導覽）、登入、帳號設定（含手機條碼載具）、我的（功能格＋會員卡、載具條碼、集點卡）、好友（加好友、邀請、好友送的券）、送券給好友、我的優惠券、優惠券 QR Code、分享頁（/s/代碼）、我的收藏
- 店家：主控台、申請新店家、店家資料、商品與服務（列表、新增、修改）、優惠管理（列表、新增、修改）、掃碼核銷、集點卡設定、店家照片上傳、**POS 收銀模式**（全螢幕、數字鍵盤，掃優惠券或會員卡、蓋章、兌換、今日紀錄）
- 平台管理：店家審核、使用者管理、營運報表

## 資料模型（Models 資料夾，15 個）
User 使用者、School 學校、StoreCategory 店家分類、Store 店家、Product 商品與服務、Coupon 優惠券、UserCoupon 我的優惠券、Redemption 核銷紀錄、Favorite 收藏、Review 評論、StampCard 集點卡、StampRecord 集點紀錄、Friendship 好友、Campaign 活動、UserBadge 徽章

## 集點卡與載具
- **集點卡**：每間店自己設定「集滿幾點換什麼」，點數只能在該店使用。顧客出示會員卡（10 位數會員編號的 QR Code），店員在 POS 按「蓋 1／2／3 點」，集滿後按「兌換」扣點。每次蓋章和兌換都會留下 StampRecord，記錄是哪位店員操作。
- **不做全平台通用點數**：點數一旦能跨店抵錢，平台就要負責結算，跟「零抽成、不經手金流」的定位衝突。
- **手機條碼載具**：會員在帳號設定填一次（格式 `/` 加 7 碼），會員卡頁會顯示 Code 39 條碼給店員掃。發票由店家自己的收銀機開立，平台不串接財政部系統、不開發票。
- 示範資料：學區便當屋集 10 點換招牌便當、放學手搖飲集 8 點換中杯飲料；示範同學在手搖飲已有 5 點。

## 版面與視覺（期末版）
- **照期中簡報第 11–15 頁的線框圖排版**：首頁依序是「定位範圍＋大字模式 → 今日優惠輪播 → 快速分類 → 店家列（左圖右文）」；底部四格「首頁｜地圖｜優惠券｜我的」；找店有「列表｜地圖」切換，地圖點店家後下方出現摘要卡；優惠券有「優惠列表｜我的優惠券」切換與「全部／快到期／附近」「可使用／已使用／已過期」分頁。
- **吉祥物「小圈」**：`Content/img/mascot-*.svg`，頭上是地圖定位針（「生活圈」的圈）。四種姿勢：揮手（註冊頁、Logo）、指路（新手導覽、地圖）、拿券開心（會員卡、邀請）、睡覺（查無資料）。全部自己用 SVG 畫，沒有版權問題。
- **圖示不用 emoji**：`Views/Shared/_Icons.cshtml` 是自己畫的 SVG 圖示組，線條圖示（`Ui.Ic("pin")`）和每個分類一張帶表情的彩色插圖（`Ui.Art(store)`）。
- **小圈會動**：SVG 檔裡內建 CSS 動畫（上下飄、眨眼、揮手、開心跳、睡覺冒 z），領券成功時會跳出來撒彩帶。系統開啟「減少動態效果」時動畫全部停止。
- **今天吃什麼**（`/Stores/Pick`）：選正餐或飲料、走路 5／10／15 分鐘、要不要有優惠，小圈從符合的店裡隨機挑一間（像拉霸一樣跑店名再停下）。
- **快到期提醒**：登入後首頁上方會提示「你有 N 張券 3 天內到期」。
- **新手導覽**：註冊完回到首頁會自動開始，畫面變暗、只把要按的地方圈起來，小圈在旁邊用一句話說明，共 7 步。可按「略過」或 Esc 結束，鍵盤可操作；「我的 → 重看導覽」可以再看一次。程式在 `Scripts/tour.js`，沒有用外部套件。
- **示範店家照片**：12 間示範店家用 Unsplash 免費授權的示意照片（`Content/img/photos`，來源列在 `CREDITS.txt`），店家頁會標「示意照片」，避免讓人以為是真的店。真實（OpenStreetMap）店家沒有照片，用插圖代替。
- **實體照片**：店家可在後台「店家照片」上傳店面或老闆的照片（JPG／PNG，3 MB 內，伺服器會確認真的是圖片），存在 `~/Uploads/stores`。有照片就顯示照片，沒有才用插圖。部署到 Azure 時這個資料夾要可寫入。

## 成長與行銷功能（期末加強版）
完整的行銷策略與商業模式寫在課程資料夾的「學區生活圈_行銷與商業模式.md」。
- **邀請連結**：好友頁的「邀請朋友」帶有個人邀請碼（跟集點用的會員編號分開），朋友用連結註冊後雙方直接成為好友，註冊頁會顯示「某某邀請你」。
- **新手任務**：領一張券、收藏一間店、加一位好友，完成三項得到「新手畢業」徽章。新手導覽走完會直接帶去優惠列表領第一張券。
- **等級與徽章**：領券、到店使用、收藏、交朋友、集點、邀請都會累積點數，5 個等級、11 種徽章，新解鎖時跳出慶祝。點數只用來升級，**不能折抵消費**（平台不經手金流）。
- **小圈問候**：首頁依時段打招呼並建議「幫我選早餐／午餐／飲料／晚餐／宵夜」，深夜小圈會睡覺。
- **活動檔期**（`/Campaigns`）：配合學校行事曆（考試週、社團成果展），管理者在「活動管理」開檔期，店家發券時可選擇參加。
- **精選店家**：管理者可把已加入平台的店設為精選，出現在首頁（加值方案的曝光位置）。
- **大家都在領**：最近 7 天實際被領最多次的券，數字來自真實紀錄。
- **老闆的話**：店家可以寫一句話，顯示在店家頁最上方。
- **店頭立牌**：店家後台可印出帶 QR Code 的立牌，客人掃了直接到店家頁。
- **店家主控台**：近 7 天領券與到店使用的長條圖、收藏數、集點顧客數。
- **營運報表**：成長漏斗（註冊 → 領券 → 到店 → 回訪），加上邀請、好友、集點數字。
- **店家合作頁**（`/Home/Partner`）：零抽成、三步驟上架、免費版／加值版方案、常見問題。
- **App 圖示與分享預覽**：可加到手機桌面（manifest.json），分享到 LINE 會顯示店家照片和老闆的話。
- **友善錯誤頁**：404 和錯誤頁由小圈陪伴（在 Azure 上生效；本機開發時會顯示詳細錯誤方便除錯）。
- 示範資料多了 8 位示範會員（密碼隨機、無法登入）的領券、評論、收藏紀錄，讓排行與報表有內容。

## 好友與分享
- 用對方的 10 位數會員編號加好友（雙方同時成為好友），可刪除。
- **送券給好友**：把還沒用的券轉到好友名下，對方「好友送我的券」會看到是誰送的；對方已經有同一款券就不能送。
- **分享店家／邀請朋友**：手機上會打開系統的分享選單（可選 LINE、通訊錄聯絡人等），電腦上則複製連結。網站不會讀取使用者的通訊錄。

## 店家資料來源
- **真實店家（1,428 間）**：`App_Data/osm_stores.json`，2026-11-16 從 OpenStreetMap 擷取三校周邊兩公里內有名稱的餐飲、飲料甜點、服飾、鞋子、飾品、藥妝、眼鏡店。授權為 ODbL，網站頁尾與店家頁已標示「© OpenStreetMap 貢獻者」。這些店只作為店家名錄，**不掛任何優惠**，避免讓人誤以為店家有提供折扣。
- **示範店家（12 間，名稱標「（示範）」）**：虛構店家，用來展示領券、分享、核銷流程。
- 未使用 Google 地圖的資料或照片（Google 條款禁止擷取）；店家頁提供「在 Google 地圖看照片與評論」和「看 Google 街景」的連結。
- 想更新店家資料：重新查詢 Overpass API 產生 JSON，刪除資料庫後重新執行。

## 無障礙
- 每頁可切換大字模式；有「跳到主要內容」連結、清楚的鍵盤焦點、表單都有標籤。
- 以 axe-core 4.10（WCAG 2.1 A/AA 與最佳實務規則）檢測期末版 13 個主要頁面（手機 375px 與桌機 1280px 各一次，共 26 次）加上 POS、集點卡設定等店家頁，目前沒有違規項目，也沒有橫向捲動。
- POS 畫面：深色高對比、按鍵至少 60px 高、鍵盤可完整操作，結果訊息會由讀螢幕軟體自動念出（成功用 status、失敗用 alert）。自動檢測無法涵蓋所有問題，仍建議請實際使用者試用。
- 真實店家多半沒有無障礙資料，會顯示「尚無資料」而不是「否」。

## 部署到 Azure
完整步驟見 [AZURE部署.md](AZURE部署.md)。資料庫可以先在 Azure 建立空的 `SmileDb`，網站第一次開啟會自動建表（含唯一索引）並放入示範資料；示範帳號密碼可用 App Service 的應用程式設定 `DemoPassword:Admin` 等覆蓋。

### 其他注意事項
- `Web.config` 的 `SmileContext` 連線字串改成 Azure SQL。
- 掃碼核銷要開相機，網站必須是 HTTPS（azurewebsites.net 預設就是）。
